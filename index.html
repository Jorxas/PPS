Vom Problem zur Umsetzung

Die Technik hinter dem Ablauf.

Referenz

Audio wird importiert, analysiert und mit einer ausdrücklichen Berechtigung einer Stimme zugeordnet.

Synthese

Modellprozesse, Warteschlange, Cache und Ressourcenprüfungen bleiben vom API-Dienst getrennt.

Überprüfung

Wortgrenzen und Unsicherheiten werden sichtbar. Ein fragwürdiges Alignment wird nicht als sichere Untertiteldatei ausgegeben.

Im Repository nachvollziehen

So ist der Code aufgebaut.

  • pps/api.py — HTTP-Vertrag und Fehlerzustände
  • pps/manager.py — getrennte Modellprozesse
  • pps/media.py — Import und Wiederaufnahme
  • pps/alignment.py — Ausrichtung und Unsicherheiten
